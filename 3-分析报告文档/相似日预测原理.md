# 相似日加权预测 — 详细原理文档

> 版本 v2.0 | 2026-08-02 | 基于 575 天中山市工业负荷 + 气象数据

---

## 1. 算法概述

**相似日加权平均法（Similar Day Weighted Averaging）** 是一种非参数日前负荷预测方法。核心思想：找到历史上与目标日气象条件最相似的日子，用这些日子的实际负荷曲线加权平均，作为目标日的预测负荷。

```
目标日(未知负荷) → 找历史上天气最像的3天 → 这3天的负荷加权平均 → 预测结果
```

## 3. 特征工程

### 3.1 逐时 → 逐日聚合

24 小时逐时天气 → 7 个逐日特征：

| 特征 | 符号 | 聚合方式 | 含义 |
|------|:---:|------|------|
| 日最高温 | `tmax` | `max(T_0..T_23)` | 日间最高气温 |
| 日最低温 | `tmin` | `min(T_0..T_23)` | 夜间最低气温 |
| 日均温 | `tavg` | `mean(T_0..T_23)` | 用于体感/露点替代 |
| 日降水量 | `precip_sum` | `sum(P_0..P_23)` | 是否为雨日 |
| 日总辐射 | `rad_sum` | `sum(R_0..R_23)` | 晴雨区分辅助 |
| 日均风速 | `wind_avg` | `mean(W_0..W_23)` | 风速影响 |
| 日均云量 | `cloud_avg` | `mean(C_0..C_23)` | 阴晴程度 |

### 3.2 降水等级

```
等级0: precip < 0.1 mm   — 无降水
等级1: 0.1 ≤ p < 1.0     — 小雨
等级2: 1.0 ≤ p < 10      — 中雨
等级3: 10 ≤ p < 25       — 大雨
等级4: 25 ≤ p < 50       — 暴雨
等级5: p ≥ 50            — 大暴雨及以上
```

### 3.3 季节分类

```
m ∈ {12,1,2} → 冬季(0)
m ∈ {3,4,5}  → 春季(1)
m ∈ {6,7,8}  → 夏季(2)
m ∈ {9,10,11}→ 秋季(3)
```

## 4. 相似度计算

### 4.1 标准化：z-score

为避免各因子量纲不同导致的偏差，所有数值因子先做 z-score 标准化：

```
z(x) = (x - μ) / σ
```

其中 μ、σ 是对 575 天候选池全体计算的均值和标准差。

**实际参数值（基于 575 天数据）**：

| 因子 | 均值 μ | 标准差 σ | 范围 |
|------|--------|----------|------|
| tmax | 26.4°C | 5.8°C | 10.1 ~ 38.5°C |
| tmin | 19.2°C | 5.7°C | 1.8 ~ 28.3°C |
| precip_sum | 5.0 mm | 12.2 mm | 0 ~ 108 mm |
| rad_sum | 14.0 MJ/m² | 5.6 MJ/m² | 1.0 ~ 30.2 MJ/m² |
| wind_avg | 9.8 km/h | 3.5 km/h | 2.1 ~ 22.6 km/h |
| cloud_avg | 67.5% | 24.1% | 5.2 ~ 100% |

### 4.2 因子权重（基于 395 天相关性标定）

| 因子 | 权重 | 类型 | 依据 |
|------|:---:|------|------|
| `tmin_deviation` | 0.25 | 数值 | Tmin r=0.694，夜间基线负荷最强因子 |
| `tmax_deviation` | 0.20 | 数值 | Tmax r=0.569，制冷负荷主驱动 |
| `precip_match` | 0.18 | 混合 | 雨天负荷反增 ~10%，需区分干湿模式 |
| `season_match` | 0.12 | 离散 | 秋 r=0.76 vs 夏 r=0.07，跨季节须区分 |
| `date_distance_decay` | 0.10 | 衰减 | 90 天内不衰减，之后指数衰减 |
| `dew_point_deviation` | 0.10 | 数值 | 露点 r=0.673，高湿环境下体感优于干球 |
| `weekday_match` | 0.05 | 离散 | 工作日/周末差异仅 0.7%，工业连续性极高 |

### 4.3 数值因子距离

4 个数值因子用 **曼哈顿距离**（比欧氏距离对单维度差异更敏感），乘以放大系数 SCALE=5.0 使数值距离与离散距离在同一尺度：

```
D_numeric = SCALE × [ 0.20 × |z(tmax) - z(tmax')|
                    + 0.25 × |z(tmin) - z(tmin')|
                    + 0.10 × |z(tavg) - z(tavg')|
                    + 0.10 × |z(cloud) - z(cloud')| ]
```

### 4.4 离散因子距离

#### 季节匹配

```
season_dist(d1, d2) = 0.0   同季
                      0.5   相邻季（冬→春、春→夏、夏→秋、秋→冬）
                      1.0   相反季（冬↔夏、春↔秋）
```

#### 星期匹配

```
weekday_dist(d1, d2) = 0.0   同为工作日或同为周末
                       1.0   工作日 vs 周末
```

#### 日期衰减

```
date_decay(d1, d2) = 0.0                             当 Δd ≤ 90 天
                    = 1 - e^(-(Δd-90)/180)            当 Δd > 90 天
```

近 90 天不衰减（认为天气模式相似），之后指数衰减，半衰期 180 天。

#### 降水距离（混合）

降水同时用了连续距离和等级距离，按 7:3 混合：

```
连续距离:
  diff ≤ 1mm:    cont = diff / 5.0                          → [0, 0.2]
  1mm < diff ≤ 10mm:  cont = 0.2 + (diff-1) / 45.0          → [0.2, 0.4]
  diff > 10mm:   cont = min(0.4 + (diff-10) / 200.0, 0.7)   → [0.4, 0.7]

等级距离:
  lvl_diff = |等级(target) - 等级(cand)| / 5.0              → [0, 1]

最终:
  precip_dist = 0.7 × cont + 0.3 × lvl_diff
```

对数压缩的设计意图：降水 0mm vs 1mm 的差异远大于 50mm vs 51mm（非线性），小雨和中雨的区分比暴雨和大暴雨的区分更重要。

### 4.5 综合距离

```
D_total = D_numeric + D_discrete

D_discrete = 0.18 × precip_dist
           + 0.12 × season_dist
           + 0.05 × weekday_dist
           + 0.10 × date_decay
```

### 4.6 相似度转换

距离 → 相似度的指数衰减公式：

```
similarity = e^(-D / σ) × 100%

其中 σ = median(所有候选日距离)
```

σ 是动态计算的——每个目标日的候选池不同，σ 也不同。如果候选池中距离中位数为 0.5，则距离为 0.5 的候选日相似度为 e⁻¹ = 36.8%，距离为 0 的为 100%。

**举例**：目标日 2025-07-15，夏季小雨日：

| 候选日 | 数值距离 | 离散距离 | 总距离 | 相似度 |
|--------|----------|----------|--------|--------|
| 2025-07-30 | 0.18 | 0.05 | 0.23 | 87.5% |
| 2025-07-13 | 0.21 | 0.05 | 0.25 | 86.1% |
| 2025-06-02 | 0.20 | 0.07 | 0.27 | 85.6% |

σ ≈ 0.31，距离最小的 7/30 得分最高。

### 4.7 晴雨硬约束

当目标日降水量 ≥ 0.5mm 时，候选项也必须 ≥ 0.3mm（排除晴天的候选日）。当目标日降水量 < 0.5mm 时不设限制。

## 5. 未来日期处理

对于不在预计算库中的日期（如 > 2026-07-29），分两种情况：

### 5.1 有预报数据

从侧边栏已加载的 Open-Meteo 预报数据中提取目标日逐时天气 → 聚合为 7 个日特征 → 在同季节同晴雨的历史日中，用温度差的平方和排序 → 取 Top-3。

相似度采用简单分层：第一名 95%，第二名 85%，第三名 75%。

### 5.2 无预报数据

降级为在同季节历史日中选日期最近的 3 天。相似度 = `100 - 天数差 / 3.65`。

## 6. 负荷预测

### 6.1 加权平均公式

```
         s₁ × L₁(h) + s₂ × L₂(h) + s₃ × L₃(h)
P̂(h) = ────────────────────────────────────────
                  s₁ + s₂ + s₃
```

- `P̂(h)`：目标日第 h 小时的预测负荷（MW），h = 0, 1, ..., 23
- `s_i`：第 i 个相似日的相似度（0~100%）
- `L_i(h)`：第 i 个相似日第 h 小时的历史实际负荷（MW）

### 6.2 数学解释

这等价于用相似度作为反距离加权的核函数。相似度越高的历史日，其负荷曲线在预测中的贡献越大。三个相似日的 24 小时负荷逐点加权，得到 24 个预测值。

### 6.3 为什么选 3 个相似日？

- 1 个：方差太大，极度依赖单一历史日
- 3 个：稳定性好，不同相似日之间的差异可以互相平滑
- 5 个以上：引入噪声，低相似度日期的负荷模式不具参考价值

## 7. 验证结果

本地测试 4 个代表性日期的相似日匹配结果：

| 目标日 | 特征 | Top-3 相似日 | 最高相似度 |
|--------|------|-------------|:---:|
| 2025-07-15 夏 | 小雨 3mm, 32.5°C | 7/30(87.5%), 7/13(86.1%), 6/2(85.6%) | 87.5% |
| 2025-10-15 秋 | 微雨 0.4mm, 33.8°C | 7/24(91.8%), 10/17(91.3%), 10/10(90.8%) | 91.8% |
| 2026-01-15 冬 | 晴天 0mm, 26.7°C | 1/16(95.5%), 4/3(88.7%), 1/13(88.4%) | 95.5% |
| 2025-08-03 夏 | 暴雨 18mm, 29.6°C | 5/20(83.6%), 6/20(83.5%), 6/14(82.3%) | 83.6% |

结论：
- 晴天和稳定天气下相似度可达 90~96%
- 暴雨日相似度下降到 82~84%（候选池缩小）
- 冬季相邻日（1/15 → 1/16）相似度最高，符合预期

## 8. 交叉验证：两期电站对比

为验证方法的通用性，在污水处理厂二期（8MWp 光伏）电站上做了独立验证：

| 指标 | 一期电站 | 二期电站 |
|------|:---:|:---:|
| 辐射-发电 Pearson r | 0.843 | 0.759 |
| 辐射-发电 R² | 0.711 | 0.538 |
| 斜率 (kWh/MJ) | 696 | 1110 |
| 样本量 | 360 天 | 363 天 |

**结论**：辐射作为第一驱动因子的结论在两次独立分析中完全一致。二期效率更高（斜率更大），建议两期分别建模。

## 9. 优缺点

| 优点 | 缺点 |
|------|------|
| 可解释性强 — 能追溯"为什么预测这个值" | 极端天气下候选池不足（相似度下降） |
| 不需要训练模型，无过拟合风险 | 无法捕捉长期产能变化 |
| 实现简单，运行快速（查表 < 1 秒） | 精度不如 LSTM/Transformer |
| 对负荷模式突变有一定适应性 | 依赖历史数据覆盖度 |
| 可作为深度学习模型的 baseline | 高温极值日的预测可能偏保守 |
