## 2 缺失数据

### 2.1 负荷分项数据——**优先级：高**

当前数据为园区/区域**总负荷**，无法拆分为空调、照明、充电桩等分项。

| 需求 | 粒度 | 用途 |
|------|------|------|
| 空调负荷 | 逐时（kW） | 空调调度模型约束 |
| 照明负荷 | 逐时（kW） | 可调照明功率上下限 |
| 充电桩负荷 | 逐时（kW） | SOC约束、充放电策略 |
| 其他不可调负荷 | 逐时（kW） | 基准负荷（不可调度部分） |

**替代方案**：若无分项数据，可参考公开文献中的典型工业园区负荷占比曲线进行**模拟拆分**（如空调30-40%、照明10-15%、动力20-30%）。

### 2.2 数据归属信息——**优先级：高**

| 需求 | 说明 |
|------|------|
| 数据来源园区/企业 | 名称、行业类型、规模 |
| 所在城市/省份 | 用于匹配碳排放因子和碳价 |
| 园区主要负荷类型 | 生产设备、空调、照明、充电桩各占比 |

当前无法确认数据是**单一工业园区**还是**区域电网汇总**。若为区域汇总数据，则无法直接用于园区级虚拟电厂建模。

### 2.3 光伏出力数据——**优先级：中**

| 需求 | 粒度 | 来源方案 |
|------|------|---------|
| 园区光伏装机容量 | kWp | 园区台账 |
| 历史光伏出力 | 逐时（kW） | NREL PVWatts模拟 + 当地气象数据 |
| 当地太阳辐照度 | 逐时（W/m²） | NASA POWER / ERA5 |

虽然光伏数据可通过公开气象数据 + PVWatts模型生成，但需要**园区光伏装机容量**参数。

### 2.4 碳交易与绿证数据——**优先级：中**

| 需求 | 粒度 | 来源 |
|------|------|------|
| 南方区域碳配额价格 | 日度（元/吨CO₂） | 广州碳排放权交易所 |
| CCER价格 | 日度 | 各试点碳市场 |
| 绿证交易价格 | 月度 | 中国绿色电力证书认购交易平台 |
| 电网碳排放因子 | 年度 | 生态环境部（2025年版） |
| 广东省区域电网碳排放因子 | 年度 | 同上 |

### 2.5 电价数据——**优先级：中**

当前Sheet中有"市场清算价"（日前市场出清电价），但需确认：

| 需求 | 说明 |
|------|------|
| 分时电价峰谷时段划分 | 尖峰/高峰/平段/低谷的具体时段 |
| 零售电价 vs 批发电价 | 园区实际结算用电价是否等于市场出清价 |
| 输配电价 | 是否含在已有电价数据中 |

### 2.6 调峰辅助服务数据——**优先级：低**

| 需求 | 粒度 | 用途 |
|------|------|------|
| 调峰需求信号 | 日前/实时 | 场景二（外部响应）输入 |
| 调峰补贴标准 | — | 经济收益核算 |
| 南方区域调峰辅助服务市场规则 | — | 确认是否已有省内/省间调峰市场 |

此项仅"场景二"需要，若优先做场景一可暂缓。

## 3 优先级汇总

| 优先级 | 数据 | 原因 |
|:---:|------|------|
| **高** | 负荷分项数据（或分项比例） | 直接决定模型粒度——分项调度 vs 整体优化 |
| **高** | 数据归属（园区/企业/城市） | 决定方案可信度，影响碳排放因子选择 |
| **中** | 光伏装机容量 | 方案含光伏，缺则无法建模绿电消纳 |
| **中** | 碳价/绿证价格 | 电-碳-绿三市场联动核算 |
| **中** | 分时电价峰谷时段 | 优化调度的核心输入 |
| **低** | 调峰辅助服务数据 | 仅场景二需要 |

## 4 下一步建议

1. **与王雅妮确认数据归属**：数据来自哪个园区/企业、所在城市、主要负荷构成
2. **若无法拿到分项负荷**：搜索典型工业园区负荷拆解文献，用比例法模拟拆分
3. **补充光伏数据**：基于园区所在地 + PVWatts 生成模拟光伏出力曲线
4. **搜集公开碳市场数据**：广州碳交所 + 生态环境部 + 中国绿证平台
5. **方案策略决策**：若只有总负荷，方案从"分项精细化调度"调整为"园区整体负荷优化"，论点改动点需与导师确认
