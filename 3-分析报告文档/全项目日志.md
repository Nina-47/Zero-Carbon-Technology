## 一、项目整体定位

**零碳科技创新大赛 · 命题赛道（智能控碳）**

用中山市中嘉污水处理厂的数据，做一个虚拟电厂优化调度方案，最终交付**可交互网页**。

- 厂区：中嘉污水厂，占地 30 公顷，一、二期共 20万 m³/天，三期扩建 20万 m³/天（多段 AO + 高效沉淀工艺）
- 峰值负荷约 15.6 MW
- 已有：三家污水厂 4-6 月逐时用电 + 广东电力市场 2025-2026 数据

## 三、模块二「智能调度」—— 核心成果

### 3.1 文件清单

| 文件 | 职责 |
|------|------|
| `config.py` | 集中参数：光伏/储能/分时电价/多目标权重/经济参数/柔性负荷开关 |
| `storage_optimizer.py` | 优化层：单日 24h 线性规划（scipy.linprog）|
| `pv_forecast.py` | 光伏预测：KNN 相似日 |
| `capacity_planning.py` | 容量规划：枚举方案 + 投资回报率 + 帕累托前沿 |
| `validate_optimizer.py` | 全年回测验证 |
| `decision_engine.py` | 决策引擎：预测→优化→操作建议 |
| `main.py` | CLI 入口：跑一次"明日运行决策" |

### 3.2 技术方案

**数据流入：**
```
data_source.xlsx（光伏一二期 + 负荷，365天）
合并数据集_光伏×天气.csv（光伏 + 天气，361天）
   → KNN相似日预测光伏 + 负荷预测
   → 线性规划优化储能充放电/购电/上网
   → 输出操作员建议
```

**优化模型（storage_optimizer）：**
- 变量：充电 pch、放电 pdis、SOC、余电上网 psell、购电 pgrid（+柔性负荷 flex 可选）
- 目标：`min w_cost×分时购电成本 + w_green×外购电量`（两目标 A）
- 约束：功率平衡、SOC 递推、SOC 边界、余电上网≤光伏

**预测（pv_forecast）：**
- KNN 相似日：逐时辐射相关性匹配历史相似日，加权合成逐时光伏
- 日总量 MAPE ~29%（框架正确，精度待优化）

## 四、关键结论（模型调试中反复确认）

1. **光伏规模受面积约束**：30公顷 → 可装12MW → 绿电天花板 22%。加大光伏（×3.8）违反面积约束。

2. **储能定位**：不发电、不直接提绿电，价值在于"解决夜间光伏缺位 + 削峰降需量"。套利需用目录分时价（价差0.79~1.05元），若用现货价（价差0.2元）则174年才回本。

3. **绿电天花板 = 光伏发电 ÷ 总用电**，柔性负荷（曝气、泵等）无论怎么调都突破不了（夜间31.8%负荷无光伏）。柔性负荷默认关闭，仅作概念保留。

4. **自发自用 >> 买绿电**：自发光伏度电成本0.118元、1.7年回本；买绿电环境溢价仅0.05元/度但电费照付、无资产。

5. **余电上网目标系数=0**：绝不能给负系数，否则"人为买电再上网"套利漏洞。
