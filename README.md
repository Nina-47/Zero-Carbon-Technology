# 零碳虚拟电厂 · 智能控碳系统

> 中山市中嘉污水处理厂「电-碳双驱」光储柔一体化智能调度与碳核算平台

## 一句话说清楚

用**光伏 + 储能 + 柔性曝气**三者协同，在广东分时电价与现货市场规则下对污水处理厂做每日调度，并量化碳排放与减排效益，最后做成可交互的网页应用与数字大屏。

**定位**：AI 降能降本，碳是顺带收益——省钱是所有污水厂的刚需，比"控碳"更能打动评委。

## 四大模块

### 模块一 · 负荷预测
- **KNN 相似日** + 自适应窗口日总量 + 排班日历 + 天气修正
- **残差修正 + 守门机制**（参考量化分层模型 Model 0→Strict→Model 1）：分场景缩放残差，周末多修、工作日少修、调休不修
- 日总量 MAPE ≈ 5.1%

### 模块二 · 智能调度
- **光伏预测**（KNN 相似日）+ **储能优化**（linprog 线性规划）+ **柔性曝气**（双模式滞回状态机）
- 双目标：分时购电成本 + 外购电量
- 输出：全年 365 天逐时调度建议（`yearly_dispatch.json`）

### 模块三 · 碳核算
- **三账分离**：企业清单账（范围一 CH₄/N₂O + 范围二购电）、项目减排账（BE-PE-LE）、LCA 全生命周期
- **双因子体系**：EF_report（广东 0.4419）+ EF_opt(t)（现货电价代理构造时变碳因子）

### 前端 · 可交互网页
- **5 个模块**：项目概览 → 天气总览 → 负荷预测 → 智能调度 → 碳效益核算
- **侧边栏随模块切换**显示对应参数
- 智能调度/碳核算都支持**日/月/年**粒度查询

## 核心创新点

1. **电-碳双驱调度**：把广东电力现货节点实时电价映射为时变碳因子 `EF_opt(t)`（高价=火电顶出高碳、低价=新能源大发低碳），让电价信号天然携带碳强度信息，实现经济收益与减碳双目标协同，而非单纯"谷电套利"。

2. **三账分离碳核算**：企业清单账 / 项目减排账 / LCA 三本独立碳账，解决储能场景下「电费节约、厂区合规排放、电池隐含碳」互相混淆的问题，规避重复计算，满足第三方核查。

3. **残差修正 + 守门机制**：参考量化分层模型（相似日基线 → 残差修正 → 分场景守门），按周末/工作日/调休分场景缩放残差修正力度，周末多修、工作日少修、调休不修，避免"一刀切"过修伤害精度。

4. **双模式滞回柔性曝气**：用「负荷波动率 + 连续低曝气时长」两个代理指标，构建节能(65%)/安全(80%)双模式滞回状态机，在保障污水处理出水达标和微生物安全的前提下主动下调曝气、消纳光伏。

5. **谷电碳悖论识别**：识别出广东现货市场下「谷电碳强度可能高于峰电」的悖论，用真实节点电价验证时变碳因子，避免"低价谷电储能反而增碳"的隐性风险。

## 快速运行

```bash
# 前端（Streamlit）
cd 1-天气分析平台程序/weather-load-platform
pip install -r requirements.txt
streamlit run app.py

# 模块二 · 全年调度回测
cd 模块二/智能调度
python validate_optimizer.py

# 模块二 · 逐日调度导出 JSON
python export_yearly_dispatch.py

# 模块三 · 碳核算
cd 模块三/code
python run_carbon.py
```
