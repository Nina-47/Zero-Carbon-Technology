# 模块二 · 智能调度

> 零碳虚拟电厂 · 中山市中嘉污水处理厂示范

## 一句话

AI 智能控碳，本质是 **AI 降能降本、碳是顺带收益**。用"光伏 + 储能 + 柔性曝气"三者协同，在广东分时电价下做每日运行调度，落地为可交互网页。

## 核心结论（全部有出处）

| 指标 | 数值 |
|:---|:---:|
| 装机 | 12.8MW 光伏（面积上限）+ 4MWh/2MW 储能 + 柔性曝气（双模式） |
| 绿电占比 | **23.96%** |
| 年节省 | **700 万元**（真实节点电价口径）|
| 回收期 | **7.58 年** |
| 弃光 | **0** |

## 方法要点（答辩必讲）

1. **绿电上限 23.96%**：光伏受 30 公顷面积约束（最多装 12.8MW），这是物理上限不是"没做好"。价值在复制推广——一个厂这么多，100 个厂放大。

2. **储能不"提绿电"**：储能不发电，反而低谷买电。它的战场是削峰降需量（省基本电费）+ 套利。柔性负荷才是"既提绿电又省钱"的手段（降低总曝气量）。

3. **双模式滞回**（专利1）：节能模式（曝气下限65%）↔ 安全模式（80%），用"负荷波动率 + 连续低曝气时长"两个代理指标触发，防微生物缺氧。

4. **分区按需供气**（专利4）：下调曝气不是"一刀切降总量"，是消除末端过量曝气，不降关键区溶解氧。

## 数据口径说明（诚实备注）

- 负荷预测当前用**三厂合计**缩放回单厂（缺单厂天气对应数据），属示范口径。
- 光伏预测日总量 MAPE ~27%（只靠辐射这一个可预测输入的现实天花板，晴天已 15%）。
