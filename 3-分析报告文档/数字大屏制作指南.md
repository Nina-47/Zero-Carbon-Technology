# 零碳虚拟电厂智能调度大屏 — 制作指南

> 基于 Zmetaboard AI Board 平台（zmetaboard.com），自然语言驱动生成。

---

## 一、平台机制

Zmetaboard 的 AI Board 功能通过自然语言描述生成大屏，核心流程：
1. 描述视觉规范（配色、字体、风格）
2. 描述布局结构（面板位置、尺寸比例）
3. 描述每个面板内容（KPI / 图表 / 表格）
4. 绑定数据集（上传 CSV/Excel 或手动录入）
5. 迭代微调（发指令改细节）

平台底层用 Three.js 渲染 3D 地图、ECharts 渲染图表、React 管理布局。

---

## 二、制作步骤

### 第 1 步：定视觉规范

```
我要做一个"零碳虚拟电厂智能调度大屏"，1920×1080 固定画布。

视觉规范：
- 风格：绿色科技 HUD 风格，深色背景
- 主色：亮翠绿 #00e396，辅助色青蓝 #00b4d8
- 背景：深黑绿渐变 #0a1628 → #0d2137
- 面板：半透明暗场，直角，细绿描边
- 预警色：黄橙 #f2a23a，异常色：红橙 #ef4444
```

### 第 2 步：搭骨架

```
页面骨架（五层）：
1. 顶部标题栏：左侧系统名称，右侧时间 + 天气
2. 中央地图：广东省 3D 深色地图
3. 左侧面板：碳排放 + 碳配额
4. 右侧面板：负荷预测 + 电价调度
5. 底部 KPI 带：碳排放总量、绿电占比、收益、配额剩余、系统状态
```

### 第 3 步：填内容 — 左侧面板

```
左侧面板：
- 实时碳排放：大数字 + 单位，下方碳配额环形进度图 + 剩余配额
- 碳排放趋势：近7天折线面积图
- 碳减排贡献：横向柱状图（光伏减排/储能调峰/负荷优化）
```

### 第 4 步：填内容 — 右侧面板 + 底部

```
右侧面板：
- 实时电力负荷：总负荷 + 三公司分项柱状图
- 负荷预测曲线：24小时折线 + 置信区间 + 峰谷标注
- 分时电价调度建议：时段标签 + 电价 + 充放电策略表格

底部：横排5个KPI卡片，标签在上、数值在下
```

### 第 5 步：细节打磨

```
优化清单：
1. 配色做减法：只用翠绿(正常) + 黄橙(关注) + 红橙(异常) 三种功能色
2. 去掉发光边框，改用 1px 半透明描边
3. 数字强制等宽字体 tabular-nums
4. 字号体系：标题13px灰绿全大写 / KPI 40px亮绿粗体 / 标签11px灰色
5. 顶部加数据刷新倒计时 + 数据源状态灯
6. 系统状态拆成三个子系统独立指示灯
7. 分时电价条移到地图下方居中，KPI移到右侧垂直排列
```

## 六、常用优化指令速查

| 想做什么 | 指令关键词 |
|----------|-----------|
| 改配色 | "把XX颜色换成XX，减少颜色种类" |
| 调字号 | "XX面板的XX字号改大/改小到XXpx" |
| 调布局 | "把XX面板移到XX位置" |
| 加动画 | "给XX加脉冲/呼吸/滚动动画" |
| 加实时感 | "加数据刷新倒计时、数据源状态灯" |
| 去花哨 | "去掉发光边框/脉冲动画，走克制路线" |
| 调地图 | "地图透明度降低/城市标记缩小/只显示告警" |
| 字体统一 | "所有数字用等宽字体 tabular-nums" |
