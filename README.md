# 零碳科技 · 智能控碳虚拟电厂

零碳科技创新大赛（命题赛道·智能控碳）项目：基于三家污水处理厂逐时用电数据 + 广东电力市场规则，构建**虚拟电厂优化调度方案**，最终交付**可交互网页**。

方案主线：`负荷预测 → 碳核算 → 优化调度 → 可视化`。

## 项目结构

```
├── 03_预测代码/          核心算法（Python）
│   ├── 负荷预测/          负荷预测（HW + KNN，日总 MAPE ≈ 5.5%）
│   ├── 优化调度/          光储优化调度 + 容量推荐器
│   ├── 碳核算/            碳排放核算（三账分离）
│   └── 主流程/
│       └── run_pipeline.py  四模块闭环主流程（预测→调度→碳核算）
├── 前端/                 streamlit 网页（可交互可视化）
└── 01_项目文档/          方案文档
```

## 快速开始

- 环境：Python 3.12
- 跑闭环主流程：
  ```bash
  python 03_预测代码/主流程/run_pipeline.py [厂名] [预测天数] [训练天数]
  ```

## 说明

- 原始数据（污水厂用电 / 天气 / 电价）与结果文件**未上传**，需本地运行生成。
- 负荷口径为「实际用电量」列（含光伏自发自用）。
