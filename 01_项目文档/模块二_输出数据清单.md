# 模块二 · 输出数据清单

> 模块二（优化调度）的输出，只服务两个下游：**大屏可视化** + **碳核算（模块三）**。
> 多余字段一律不产出。写代码时按此清单对齐。

## 核心：一个电能平衡方程

```
净购电 = 负荷 − 光伏自用 − 储能放电 + 储能充电
```

大屏画这些曲线，碳核算用「净购电」算范围二。

---

## 一、逐时曲线（每小时，24h × N天）

| 字段 | 含义 | 大屏 | 碳核算 |
|------|------|:---:|:---:|
| `load_kW` | 厂区实际用电（总负荷，柔性调整后） | ✅ | ✅ 能耗基准 |
| `pv_kW` | 光伏出力 | ✅ | ✅ 绿电拆分 |
| `pv_self_kW` | 光伏自发自用 | ✅ | ✅ |
| `pv_sell_kW` | 余电上网 | ✅ | ✅ 上网碳抵减 |
| `pch_kW` / `pdis_kW` | 储能充电/放电 | ✅ | ✅ 储能减碳拆分 |
| `soc` | 荷电状态 | ✅ | ❌ |
| `pgrid_kW` | **净购电** | ✅ | ✅ **范围二核心** |

## 二、日/年汇总

| 字段 | 含义 | 大屏 | 碳核算 |
|------|------|:---:|:---:|
| `净购电量` MWh | 从电网买多少 | ✅ | ✅ **范围二 = 净购电 × 0.4419** |
| `余电上网量` MWh | 卖回电网多少 | ✅ | ✅ 绿电碳抵减 |
| `储能充/放电量` MWh | 储能吞吐 | ✅ | ✅ 储能减碳贡献 |
| `绿电占比` % | 绿电覆盖率 | ✅ | ❌ |
| `购电成本` 元 | 全年电费 | ✅ | ❌ |

## 三、不产出（多余）

| 字段 | 为什么砍 |
|------|---------|
| `flex` / `flex_down`（柔性负荷/曝气下调） | 专利概念，非大屏/碳核算核心，可作可选开关 |
| `objective_value` | LP 求解器内部值 |
| `chg_pv_kwh` / `dis_replace_kwh` | 储能减碳中间拆分，需要时后置 |

---

## 输出格式约定

- **单位**：功率 kW（1h 电量 kWh = 功率值 × 1h，数值相等），能量汇总用 kWh/MWh
- **格式**：逐时宽表（日期 + 24h）+ 逐日汇总，与负荷分表同构
- **落点**：`04_预测输出/V4_优化调度/`
