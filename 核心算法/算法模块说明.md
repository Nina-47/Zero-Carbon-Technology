# 核心算法模块说明（最新版）

> 本目录是「零碳科技 · 智能控碳虚拟电厂」的核心算法，含四个模块 + 工具脚本。
>
> ⚠️ **这是最新版。** 仓库根目录下的 `负荷预测_v2.py`、`src/prediction/`、`config.py` 里的
> 预测配置是**旧版**，后续开发请以本目录为准（旧版可择期清理）。

## 一、模块总览

| 模块 | 干什么 | 主入口 | 关键指标 |
|------|--------|--------|----------|
| `负荷预测/` | 预测未来逐时用电负荷 | `负荷预测_v2.py` | 日总 MAPE ≈ 5.5% |
| `优化调度/` | 光储充放电调度 + 容量规划 | `main.py` | 多目标（成本/绿电/碳） |
| `碳核算/` | 三账分离碳排放核算 | `run_carbon.py` | scope1 + scope2 + 减排 |
| `主流程/` | 四模块闭环（预测→调度→碳核算） | `run_pipeline.py` | 一键跑全流程 |

## 二、各模块输入输出

### 1. 负荷预测
- **输入**：历史逐时用电 + 天气（温度 / 降水 / 辐射）
- **输出**：未来 N 天逐时负荷预测（kW）
- **方法**：HW（Holt-Winters）+ KNN 相似日模板匹配

### 2. 优化调度
- **输入**：负荷预测 + 分时电价 + 光伏出力
- **输出**：7×24 小时充放电决策 + 成本/收益 + 减排量
- **方法**：线性规划（scipy `linprog`），168 个决策变量

### 3. 碳核算
- **输入**：用电量 + 排放因子 + 光伏/储能参数
- **输出**：scope1（工艺）/ scope2（电力）/ 光储减排 ER
- **方法**：三账分离（企业清单账 / 项目减排账 / LCA 账）

### 4. 主流程
- 把上面三个串起来，一键跑通「预测 → 调度 → 碳核算」，输出汇总 JSON。

## 三、数据说明

  - `yearly_dispatch.json` —— 年度调度结果
  - `阶段4灵敏度对比.png` —— 调度灵敏度分析图

## 四、前端怎么接（两种，推荐第一种）

1. **读预计算结果（推荐）**：前端直接读 `data/核心算法结果/*.json` 做展示。
   简单、快、不用跑算法、不依赖原始数据。
2. **实时调用**：`import` 各模块函数，前端传参实时计算。灵活，但需要数据和环境。
